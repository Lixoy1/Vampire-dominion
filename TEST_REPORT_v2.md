## Что проверить после GitHub Pages

1. Открыть сайт — на Главной прирост и итог должны быть `—`.
2. Перейти в Господство — все поля пустые.
3. Ввести только `1` в текущее господство — должно быть `1 M`, прирост `0`, итог `1 M`.
4. Нажать «Обнулить всё» — снова пусто, без миллионов.
5. Добавить смотрителя и уровень, но не таланты — кровь может посчитаться, прирост должен быть `—` до заполнения текущих уровней талантов.
6. На мобильном экране вверху должны одновременно быть видны 8 вкладок в сетке 4×2.
7. В hero должен быть виден арт ОПТИМИСТА; текст находится в нижней части на мобильном и не заменяет изображение.
