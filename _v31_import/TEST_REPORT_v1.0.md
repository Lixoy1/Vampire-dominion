## Исправление универсальности
В пользовательские входы добавлены ранее «запечённые» значения примера:
- BD2 — кровь за 1 сбор
- BE5:BE14 — карты, жетоны, флакон, бутыль
- T/V/X/Z/AB22:25 — единицы K/M распределения книг

Теперь пользовательский движок очищает эти значения перед расчётом.
