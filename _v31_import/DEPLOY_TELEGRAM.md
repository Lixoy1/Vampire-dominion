# Развёртывание в Telegram за 10–15 минут

## 1. Создать бота

В Telegram откройте официального `@BotFather`:

1. `/newbot`
2. задайте название;
3. задайте username, заканчивающийся на `bot`;
4. сохраните токен в безопасном месте. Для этой статической версии токен в код Mini App **не вставляется**.

## 2. Опубликовать Mini App

Самый простой бесплатный вариант — GitHub Pages:

1. новый публичный репозиторий;
2. загрузить все файлы проекта в корень;
3. `Settings → Pages`;
4. Source: `Deploy from a branch`;
5. Branch: `main`, Folder: `/ (root)`;
6. сохранить и дождаться HTTPS URL.

## 3. Привязать к боту

В `@BotFather`:

- `My Bots` → ваш бот → `Bot Settings` → `Configure Mini App` / `Main Mini App`;
- укажите HTTPS URL GitHub Pages.

После настройки в профиле бота появится кнопка запуска приложения. Main Mini App также можно открывать deep-link вида:

`https://t.me/BOT_USERNAME?startapp`

## 4. Проверить перед раздачей ссылки

1. Открыть приложение **из Telegram**, не только в Safari.
2. Убедиться, что сверху зеленая строка «Самотест пройден».
3. Проверить ввод чисел, выбор смотрителя, возврат между вкладками.
4. Закрыть и открыть Mini App — данные должны сохраниться локально на устройстве.
5. Сверить один реальный расчет с Excel.

## Безопасность

- Никогда не помещайте bot token в `index.html`, `app.js` или публичный GitHub.
- `initDataUnsafe` нельзя использовать как доказательство личности на сервере. Если позже появится backend/облачные профили, валидируйте `Telegram.WebApp.initData` на сервере по официальной документации Telegram.
- Текущая версия не имеет backend и не отправляет пользовательские данные наружу.
