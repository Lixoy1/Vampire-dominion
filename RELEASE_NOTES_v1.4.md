## Исправлена логика основной книги

1. Исправлена сумма бонуса Вдохновения для Силы (`AE2`).
2. Исправлены формулы книг ×15 в строках Сила/Харизма/Интеллект/Воля: теперь используются номиналы 100 и 1000, а не ошибочные количества предметов из текущей строки.
3. `AG24` и `AG25` больше не являются закэшированными числами одного игрока — это динамические суммы «Бонус книг» по пяти основным смотрителям, как и соседние строки.
4. Контрольный сценарий обновлён: прирост 86.465485126 M, итог 361.325485126 M.

## Шаг №05 теперь соответствует инструкции

Ранее блок был неверно описан как распределение/старые книги. Теперь он просит у пяти основных смотрителей именно значения **«Бонус книг»** по Силе, Харизме, Интеллекту и Воле из подробностей атрибутов. Эти значения нужны для дополнительного процента книг от Конклава.

## Вдохновение

Уточнено важное правило: текущий бонус Вдохновения — часть исходного состояния аккаунта. Если источник Вдохновения уже открыт, его текущий процент нужно внести даже без планируемого повышения, потому что он влияет на прирост основных смотрителей. Поле «Добавлю» отвечает только за план.

## Таланты

- пороги ×1…×6: 200 / 400 / 600 / 800 / 1000 / 1200 Talent EXP;
- рейтинг считается по фактическому Talent EXP у смотрителя и выбранному максимальному коэффициенту;
- свитки 200 / 100 / 50 показываются сначала как нераспределённый запас EXP;
- гарантированные рукописи ×1 считаются отдельно;
- ×2…×6 отображаются как вероятностная оценка и не прибавляются к гарантированному итогу;
- добавлен планировщик Talent EXP от прорывов 100/150/200/250/300/350.

## Близость / Влечение

- фиксированные предметы считаются точно;
- случайные предметы: минимум / средняя оценка / максимум;
- добавлена проверка заданной цели;
- исправлена ошибка первой копии исходной таблицы Близости: минимум Шкатулки близости теперь входит в минимальный итог.

## Сбор ресурсов

Точный калькулятор: один сбор × коэффициент жетона 0.1 / 0.5 / 1 / 2 / 3 / 5 / 10, карта сбора ×1. Поддерживаются K/M/B, текущий запас и цель.

## Самопроверка

Помимо полного контрольного примера основной книги проверяются мини-сценарии талантов, Близости, Влечения и сбора ресурсов. Обычный пользователь видит только две лампы состояния.
