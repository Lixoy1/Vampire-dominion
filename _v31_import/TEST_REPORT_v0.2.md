# TEST REPORT v0.2

Проверено локально:

- `app.js` проходит `node --check`.
- `engine-data.js` проходит `node --check`.
- Все локальные ассеты доступны через HTTP 200.
- `index.html` корректно ссылается на `styles.css`, `app.js`, `engine-data.js` и папку `assets/`.
- Статические ID интерфейса, используемые расчетным кодом, присутствуют; `tab-*` создается по динамическому имени вкладки.
- Расчетное ядро и контрольный пример «Надя 495» не изменены при редизайне.
