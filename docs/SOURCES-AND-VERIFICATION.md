# Реестр источников: «Наследие Вампиров»

Этот файл отделяет подтверждённые сведения от подсказок и непроверенных данных. Наличие источника в списке само по себе не означает, что его цифры уже внесены в калькулятор.

## Приоритет источников

1. **Скриншот из актуальной версии игры** с видимыми названием системы, уровнем, текущим и следующим значением, ценой улучшения и сервером/версией, если они важны.
2. **Официальные объявления и примечания к обновлениям**: https://t.me/gov_announcements и официальная группа https://t.me/gov_ruofficial.
3. **Игровые сообщества и гайды**. Использовать как указатель на механику или для поиска недостающих данных, затем по возможности сверять цифры с игрой.
4. **Калькуляторы и боты сообщества**. Сравнивать как независимую реализацию; не считать их числа эталоном без контрольного примера из игры.

## Что уже подтверждено для проекта

- В репозитории есть старая расчётная база engine.js, data.js, engine-data.js и контрольные примеры. Их нельзя заменять новыми приблизительными формулами.
- Для старого калькулятора сохранены ранее проверенные контрольные значения. Новые функции должны проходить регрессионные проверки, не меняя их.
- Скриншоты инвентаря и игровых экранов, предоставленные владельцем проекта, могут быть первичным источником для конкретных состояний аккаунта. Но один скриншот одного уровня не доказывает формулу для всех уровней.

## Как регистрировать каждое значение

Для каждого ряда данных фиксировать:
- система и точное название параметра;
- уровень/звёзды/ранг и условия;
- текущее значение, следующее значение и стоимость;
- единицы измерения и правило округления;
- точный URL поста или имя файла/скриншота;
- дата проверки и версия игры, если известна;
- статус: verified-in-game, official-note, community-unverified, unknown;
- контрольный пример, который можно повторить вручную.

## Правило публикации

Число не становится встроенной константой, пока не имеет источника и повторяемого контрольного примера. Если данные неполные или источники расходятся, показывать предупреждение и не выдавать предположение за точный расчёт. Изображения из сообществ использовать только с атрибуцией и с учётом разрешения/условий источника; предпочтительны собственные скриншоты игры или официальные материалы.
