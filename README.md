# Vampire Dominion — Blood Moon Edition

Самостоятельный локальный калькулятор для браузера и статического хостинга (например, GitHub Pages). Все расчёты выполняются в браузере, профиль хранится в `localStorage`, экспортируется и импортируется в JSON. Приложение не обращается к закрытому API игры и не зависит от внешнего CDN изображений.

## Что включено

- 9 разделов: Господство; Конклав и Сад; Уровни и Кровь; Таланты и Опыт; Вдохновения и Веяния; Кровные узы; Облики; Призыв; Сумка и Очки.
- База: 68 смотрителей, 45 спутников, 237 предметов, 8 ступеней прорыва, 180 уровней Конклава, 210 уровней Сада, 155 строк кривых Веяний и RU/EN словари.
- 496 оригинальных локальных изображений WebP: 68 смотрителей, 86 вариантов изображений спутников, 237 предметов, 105 обликов.
- Автораспределение доступных ресурсов Конклава, Сада и уровней смотрителей; локальные расчёты сумки, опыта гильдии, Близости, Влечения и Кровных уз.
- Редактирование профиля, уровней талантов, параметров партнёров и целей Кровных уз.
- Локальное сохранение, импорт и экспорт профиля.
- Оформление Blood Moon с пользовательской обложкой и авторским стикером.

## Запуск локально

Нужен Python 3 или Node.js. Из корневой папки проекта запустите один из вариантов:

```bash
python -m http.server 8080
```

или

```bash
npx serve .
```

Откройте `http://localhost:8080`. В Windows можно запустить `start_windows.bat`. Не открывайте `index.html` напрямую через `file://`: современные браузеры могут блокировать ES-модули в этом режиме.

## Проверки

```bash
npm test
npm run check
python verify_icons.py
```

## Структура

- `index.html` — точка входа.
- `scripts/app.js` — UI, профиль, навигация и обработчики.
- `scripts/engine.js` — расчётное ядро.
- `scripts/data.js` — база данных и пути к локальным изображениям.
- `data/` — исходные таблицы JSON.
- `assets/icons/` — 496 локальных WebP-изображений.
- `assets/brand-hero.png` и `assets/brand-sticker.png` — предоставленные пользователем материалы оформления.

## Примечание по формулам

Калькулятор воспроизводит формулы, реализованные в приложенном движке v3.0. Некоторые участки самого движка прямо обозначены в исходнике как аппроксимации (например, стоимость уровня в Крови и Кровных уз). Они не объявляются подтверждёнными точными игровыми формулами без контрольных игровых значений.
