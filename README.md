# Vampire Dominion v1.0 RC — OPTIMIST

Универсальный неофициальный калькулятор для игроков «Наследие Вампиров».

## Главное изменение v1.0
Предыдущие версии переносили формулы Excel, но несколько значений из контрольного примера оставались статическими внутри движка. В v1.0 пользовательский расчёт очищает и связывает все обнаруженные пользовательские параметры, включая:
- кровь за один сбор;
- карты, жетоны, флаконы и бутыли;
- единицы K/M в распределении книг.

Контрольный пример хранится только для self-test и не участвует в обычном пользовательском расчёте.

## Что считает
- текущее и итоговое господство;
- Конклав и стоимость баллов совета;
- до 5 основных прокачиваемых смотрителей;
- уровни, кровь, таланты, рукописи, гарантированные повышения и Talent EXP;
- книги пяти типов;
- распределение прироста книг по смотрителям;
- Дегустацию;
- доверие партнёров;
- плазму, Вито, наследников;
- остальных смотрителей;
- общий ресурсный аудит крови;
- отдельный калькулятор талантов;
- близость / влечение;
- быстрый расчёт сборов.

## Контрольный сценарий
Встроенный тест воспроизводит заполненный пример:
274.86M → +87.565034026M → 362.425034026M.

- Конклав 4.994446M

- прочее 9.1047M
- основные смотрители 56.062284752M
