# Книга Лорд-протектора — v1.4

## Как сделать полный расчёт

### 1. Основа

Перепиши текущее господство, число открытых смотрителей, запас крови и баллы совета.

### 2. Древо Конклава

Для Силы, Харизмы, Интеллекта и Воли укажи текущий уровень печати и уровень, до которого хочешь поднять. Сайт сам переведёт это в количество повышений, покажет стоимость, прибавку каждому открытому смотрителю, бонус книг и вклад в господство.

### 3. Вдохновение

Если у тебя уже открыты источники Вдохновения из списка, введи их текущий процент. Это исходный бонус аккаунта, который влияет на новый прирост основных смотрителей. В «Добавлю» указывай только планируемое повышение.

### 4. До пяти основных смотрителей

Выбирай только тех, кого реально собираешься качать. Укажи текущий/целевой уровень и фактический Talent EXP. Таланты раскрывай только при необходимости.

В строках талантов:

- текущий уровень — значение таланта сейчас;
- рукописи — сколько планируешь потратить;
- гарантированный прирост — только точные повышения;
- итог/прирост считает движок.

### 5. «Бонус книг» у основных

Это критически важный шаг при повышении процента книг Конклавом. Открой у каждого из пяти основных подробности Силы/Харизмы/Интеллекта/Воли и перепиши именно строку **«Бонус книг»**, с K/M/B.

### 6. Казна

Внеси только то, что реально собираешься использовать: сбор крови и предметы, книги, Дегустацию, доверие, Плазму, Вито, наследников и т.д.

### 7. Остальные смотрители

Если будешь тратить Talent EXP на смотрителей вне основной пятёрки, добавь их текущий уровень и EXP. В исходной модели этого этапа каждые 200 EXP считаются как гарантированный ×1.

### 8. Результат

Главная карточка показывает текущее господство → прирост → итог. Совет ресурсов показывает точную нехватку крови/баллов совета и предупреждает о незаполненных данных, которые нужны для точного Конклава.

## Таланты — отдельный рейтинг

Самый высокий коэффициент смотрителя задаёт порог:

- ×1 = 200 EXP;
- ×2 = 400;
- ×3 = 600;
- ×4 = 800;
- ×5 = 1000;
- ×6 = 1200.

Сайт считает только полные пороги. Например 3557 EXP при ×6 — два полных повышения: рейтинг 12, остаток 1157, до следующего порога 43 EXP.

Свитки 200/100/50 сначала образуют запас EXP. Распредели его по нужным смотрителям, а в калькулятор рейтинга внеси уже фактические значения после распределения.

Рукопись ×1 — гарантирована. Для ×2…×6 калькулятор показывает ожидаемый результат отдельно и не выдаёт его за гарантию.

## Близость

Точный вклад:

- обычный подарок +1;
- большой +2;
- роскошный +5;
- монеты +1/+2/+5/+25.

Случайный диапазон:

- Сумочка 1–4;
- Мешок 5–8;
- Шкатулка 4–50.

Сайт показывает фиксированную часть, минимум, среднюю оценку и максимум. Если задана цель, будет один из трёх статусов: гарантированно хватает / возможно, но зависит от случайности / даже максимум не достигает цели.

## Влечение

Точный вклад:

- Алый букет +1;
- Синий +2;
- Лиловый +5;
- записки +1/+2/+5/+25.

Случайный диапазон:

- Пиала 1–4;
- Бутыль 5–8;
- Шкатулка 4–50.

Логика результата такая же, как для Близости.

## Сбор ресурсов

Для любого ресурса вводи одно значение «за обычный сбор» и количества предметов:

- ×0.1;
- ×0.5;
- ×1;
- ×2;
- ×3;
- ×5;
- ×10;
- карта ×1.

Сайт показывает дополнительный ресурс, общий запас и точный остаток/дефицит до цели. При сборе летучих мышей учитывай отдельно запас нектара.

## Практические советы сообщества

Советы вроде «качать две команды по 5», «в Рудру лить свитки», «рукописи копить пачками», «не поднимать ненужных смотрителей выше порога Арены» — полезные стратегии игроков, но не являются обязательными формулами. В приложении они помечаются как советы.
