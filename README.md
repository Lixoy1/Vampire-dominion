# Vampire Dominion — Telegram Mini App

Неофициальный мобильный калькулятор господства для игроков «Наследие Вампиров».

## Что внутри

- `index.html` — интерфейс Mini App.
- `styles.css` — адаптивный мобильный дизайн.
- `app.js` — Telegram WebApp-интеграция, формы, валидация, сохранение и самотест.
- `engine-data.js` — расчетная модель, автоматически извлеченная из очищенной Excel-книги: формулы + справочник смотрителей.
- `.nojekyll` — чтобы GitHub Pages отдавал файлы напрямую.

Расчетное ядро — HyperFormula 3.3.0 в режиме GPLv3. Проект также распространяется под GPLv3.

## Быстрый запуск локально

Нельзя открывать `index.html` через `file://` и ожидать полноценную работу Telegram. Запустите любой статический HTTP-сервер, например:

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий, например `vampire-dominion`.
2. Загрузите содержимое этой папки в корень репозитория.
3. `Settings → Pages → Deploy from a branch → main / root`.
4. Дождитесь HTTPS-адреса вида `https://USERNAME.github.io/vampire-dominion/`.
5. Подключите URL в @BotFather как Main Mini App.

Подробно — в `DEPLOY_TELEGRAM.md`.

## Самопроверка

При старте приложение автоматически запускает контрольный пример из исходной заполненной книги «Надя 495». Проверяются ключевые клетки:

- `T72` — прирост господства;
- `T73` — конечное господство;
- `AW1` — достаточность крови;
- `T15` — необходимые баллы совета.

Если контроль не совпал, сверху будет красное предупреждение. Это сделано специально, чтобы не публиковать версию с тихо сломанной математикой.

## Важное ограничение v0.1

Движок воспроизводит математику исходной книги и дает доступ ко всем 283 ручным полям. Удобный интерфейс уже покрывает основные разделы инструкции, а редко используемые поля доступны в «Расширенных полях». Перед массовым использованием рекомендуется проверить 5–10 реальных аккаунтов против игры/Excel.

## v0.3 — темы и контроль Excel-логики

- Добавлено переключение **тёмная ↔ светлая** тема. Выбор сохраняется на устройстве и синхронизирует цвета шапки/фона Telegram Mini App.
- Светлая тема остаётся в стилистике проекта: слоновая кость, бордовый, состаренное золото, готические рамки.
- Раздел **«Проверка»** теперь показывает комплектацию расчётного ядра: формулы, ручные поля и набор функций Excel.
- В проект загружены все **806 формул** расчётной модели и все **283 ручных поля** исходного калькулятора. Не вынесенные в красивый интерфейс поля автоматически доступны в «Расширенных полях».
- Формулы используют 13 функций: `AVERAGE`, `EXP`, `IF`, `IFERROR`, `INDEX`, `INT`, `MATCH`, `MOD`, `OR`, `ROUNDDOWN`, `SUM`, `SUMIF`, `VLOOKUP`.
- Контрольный сценарий «Надя 495» сохранён и запускается автоматически при старте приложения.
