# Как обновить Vampire Dominion до v2.1

1. Распакуй ZIP на компьютере.
2. Открой GitHub → `Lixoy1/Vampire-dominion`.
3. Убедись, что выбрана ветка `main`.
4. Нажми `Add file` → `Upload files`.
5. Перетащи **всё содержимое распакованной папки**, а не сам ZIP.
6. Разреши заменить файлы с одинаковыми именами.
7. В Commit message напиши: `Vampire Dominion v2.1 — Blood Moon`.
8. Оставь `Commit directly to the main branch`.
9. Нажми `Commit changes`.
10. Подожди 1–3 минуты, пока GitHub Pages обновится.
11. Для проверки открой:

`https://lixoy1.github.io/Vampire-dominion/?v=210`

## Быстрый контроль после публикации

- На первом открытии должен быть виден главный вампирский арт.
- Вверху видны все 8 вкладок сеткой 4×2 на телефоне.
- Лампа проверки зелёная.
- В Конклаве при нехватке баллов совета показывается **точный дефицит**.
- В Ресурсах → Книги → Магия присутствуют I, II и III.
- Внизу страницы есть строка: `Создано с любовью при поддержке «Девочки моих фантазий» ♥ ♥ ♥`.
