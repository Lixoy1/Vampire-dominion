# Как обновить уже опубликованный Vampire Dominion до v1.4

1. Скачай ZIP v1.4 и распакуй его.
2. Открой GitHub → репозиторий `Vampire-dominion` → убедись, что выбрана ветка `main`.
3. `Add file` → `Upload files`.
4. Перетащи **всё содержимое распакованной папки**, а не сам ZIP.
5. Разреши GitHub заменить файлы с одинаковыми именами.
6. Сообщение коммита: `Vampire Dominion v1.4 — instruction accurate`.
7. Выбери `Commit directly to the main branch` → `Commit changes`.
8. Подожди GitHub Pages 1–3 минуты.
9. Открой сайт с `?v=14`, например:
   `https://lixoy1.github.io/Vampire-dominion/?v=14`
10. Нажми `↺ Новый расчёт`, чтобы удалить старые сохранённые значения от предыдущих версий.
11. Проверь две зелёные лампы на Главной и сделай тест: введи только текущее господство — итог должен совпасть с ним, а прирост быть 0.

Если всё зелёное, тот же URL можно использовать в Telegram Mini App.
