# Как заменить старый Vampire Dominion на v2.0

1. Скачай ZIP и распакуй его.
2. Открой GitHub → `Lixoy1/Vampire-dominion`.
3. Убедись, что слева выбрана ветка `main`.
4. Нажми `Add file` → `Upload files`.
5. Перетащи **содержимое распакованной папки**, а не сам ZIP.
6. Согласись заменить файлы с одинаковыми именами.
7. Commit message: `Vampire Dominion v2.0 — Clean Core`.
8. Выбери `Commit directly to the main branch`.
9. Нажми `Commit changes`.
10. Подожди GitHub Pages 1–3 минуты.
11. Открой:

`https://lixoy1.github.io/Vampire-dominion/?v=200`

## Очень важно

v2.0 не использует расчётные данные старых версий вообще. Но параметр `?v=200` помогает браузеру не показывать закэшированные CSS/JS v1.x.

После открытия сверху должна загореться зелёная лампа:

**«Проверка пройдена · расчётный движок готов»**.
