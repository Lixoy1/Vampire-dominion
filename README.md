# Vampire Dominion v2.0 — Clean Core

Полностью переписанная версия калькулятора для «Наследия Вампиров».

Создатель проекта: **ОПТИМИСТ** — **@optimist2408**.

## Главное отличие v2.0

- расчётный движок написан с нуля на чистом JavaScript;
- HyperFormula/Excel-движка в браузере больше нет;
- заполненный пример Excel **никогда не попадает в пользовательские поля**;
- расчётное состояние **не сохраняется в localStorage** — сохраняется только светлая/тёмная тема;
- после открытия и после кнопки «Обнулить всё» каждый расчётный модуль равен нулю;
- каждый крупный блок из исходных таблиц вынесен в отдельную понятную вкладку.

## Проверка

В `engine.js` встроена самопроверка по заполненным контрольным примерам исходных файлов. На старте сайта зелёная лампа появляется только если все проверки пройдены.

Дополнительный запуск локальных тестов:

```bash
node test-engine.js
```
