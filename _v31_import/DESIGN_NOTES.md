# Vampire Dominion — OPTIMIST Edition v0.2

## Визуальная концепция
- Готический вампирский интерфейс: графитовый/черный фон, бордовый акцент, приглушенное золото.
- Верхний hero использует предоставленный пользователем референс «Наследие Вампиров» как атмосферный фон с затемнением для читаемости.
- Отдельный блок создателя: **ОПТИМИСТ**, Telegram **@optimist2408**.
- Герб `assets/crest.svg` создан специально для проекта и не копирует официальный логотип игры.
- Интерфейс mobile-first и рассчитан на Telegram WebView/iPhone.

## UX
- Результат господства вынесен на первый экран.
- Навигация закреплена сверху при прокрутке.
- Пустые слоты смотрителей явно описаны как нейтральные для расчета.
- Раздел проверки содержит эталонный самотест «Надя 495».
- Служебные/редкие поля спрятаны в «Расширенные поля».
