# Источники Vampire Dominion v2.1

## Расчётные материалы проекта

- `Kalkulyator_gospodstva_Nadya_495.xlsx` — заполненный контрольный пример господства.
- визуальная вкладка-инструкция основного калькулятора.
- `Калькулятор таланта.xlsx` и PDF-представление.
- `Таланты_как их считать.pdf`.
- `БлизостьВлечениеРесурсы.xlsx`.
- присланные скриншоты предметов Близости, Влечения и Магии II.
