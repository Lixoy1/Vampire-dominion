# Vampire Dominion v1.4 — Lord Protector

Неофициальный мобильный калькулятор и игровой помощник для «Наследие Вампиров: Новолуние».

**Создатель проекта:** ОПТИМИСТ — @optimist2408

## Что умеет

- полный план прироста господства по логике исходной таблицы;
- Древо Конклава с ценой баллов совета, прибавкой атрибута и бонусом книг;
- текущий и планируемый бонус Вдохновения;
- до 5 основных смотрителей: уровень, кровь, Talent EXP, рукописи и гарантированные повышения;
- точный шаг «Бонус книг» у пяти основных смотрителей;
- книги, Дегустация, доверие, наследники и дополнительные источники господства;
- остальные смотрители и их Talent EXP по модели основной таблицы;
- отдельный калькулятор рейтинга талантов;
- Близость / Влечение: фиксированная часть, минимум, среднее, максимум и проверка цели;
- сбор Крови / Нектара / Летучих мышей по жетонам и картам;
- гайды и подсказки для новичка;
- тёмная и светлая тема;
- Telegram Mini App / обычный мобильный браузер.

## Главный принцип v1.4

Интерфейс больше не просит пользователя разбираться в Excel. Он задаёт игровые вопросы: **что есть сейчас → что планируешь сделать → сколько ресурсов есть → что получится → чего не хватает**.

Точные формулы, вероятностные оценки и советы игроков визуально разделены.

## Расчётное ядро

- 808 формул основной книги после проверенных исправлений;
- 314 пользовательских входов;
- 65 смотрителей во встроенной базе;
- внутренний контрольный сценарий;
- отдельные мини-тесты для талантов, Близости/Влечения и сбора ресурсов.

Пользовательский экземпляр движка всегда запускается с пустыми ручными полями. Заполненный пример используется только для скрытой самопроверки.

## Важное изменение эталона

После детального повторного аудита обнаружены явные технические ошибки исходной книги: формула Силы Вдохновения, номиналы двух групп книг ×15 и две закэшированные суммы «Бонус книг». После исправления контрольный пример даёт:

- прирост господства: **86.465485126 M**;
- итоговое господство: **361.325485126 M**;
- доступная кровь: **100.713022 B**;
- необходимая кровь: **89.0439971 B**;
- баллы совета: **62.44 M**.

Старые 87.565034026 M / 362.425034026 M больше не используются как эталон, потому что воспроизводили ошибки исходных формул.
