# Vampire Dominion v1.0.1 — размещение на GitHub Pages и в Telegram

## 1. Что загружать
Распакуйте ZIP. В корне архива уже лежит `index.html` — именно содержимое архива нужно загрузить в корень репозитория GitHub.

Главные файлы:
- `index.html`
- `styles.css`
- `app.js`
- `engine-data.js`
- `.nojekyll`
- папка `assets/`

Не загружайте сам ZIP как единственный файл.

## 2. Обновление существующего репозитория
Откройте GitHub → репозиторий `Vampire-dominion`.

Если там уже лежит старая версия:
1. Откройте вкладку **Code**.
2. Нажмите **Add file → Upload files**.
3. Перетащите все файлы и папку `assets` из новой сборки.
4. Согласитесь на замену файлов с одинаковыми именами.
5. Внизу в Commit message напишите: `Vampire Dominion v1.0.1`.
6. Нажмите **Commit changes**.

Если GitHub через браузер не позволяет удобно заменить папку `assets`, можно удалить старые файлы в `assets` и загрузить папку заново.

## 3. Проверка GitHub Pages
Откройте **Settings → Pages**.

Должно стоять:
- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/(root)`

После коммита подождите обычно 1–5 минут. Адрес остаётся прежним, например:
`https://lixoy1.github.io/Vampire-dominion/`

Откройте ссылку в режиме инкогнито или обновите страницу без кэша, чтобы не увидеть старую версию.

## 4. Что проверить до Telegram
На чистом запуске:
1. В верхнем баннере виден ОПТИМИСТ в вампирском стиле.
2. Итоговое господство показывает `—`, пока не введено текущее господство.
3. Введите только текущее господство: итог должен стать равен введённому значению, прирост — 0.
4. Переключатель светлой/тёмной темы работает.
5. Откройте **Проверка** и запустите self-test. Контрольный заполненный пример должен пройти.
6. Введите один реальный сценарий игрока и проверьте живые статусы «хватает / не хватает».

## 5. Подключение к Telegram BotFather
Если бот уже создан, новый создавать не нужно.

В `@BotFather`:
1. `/mybots`
2. Выберите вашего бота.
3. **Bot Settings → Configure Mini App**.
4. Укажите HTTPS-адрес GitHub Pages.
5. Сохраните.

Для кнопки меню:
1. `/setmenubutton`
2. Выберите бота.
3. Вставьте тот же HTTPS URL.
4. Название кнопки, например: `👑 Калькулятор`.

## 6. Если Telegram показывает старую версию
Telegram WebView может держать кэш. Тогда:
- полностью закройте Mini App и Telegram;
- откройте снова;
- либо временно добавьте к URL `?v=14`, например `https://lixoy1.github.io/Vampire-dominion/?v=14` и сохраните URL в BotFather.

## 7. Безопасность
Токен бота не нужен внутри этого статического Mini App. Не добавляйте токен BotFather в GitHub, `app.js`, HTML или публичные файлы.


## После обновления
Открой сайт с параметром `?v=14`, например `https://USERNAME.github.io/Vampire-dominion/?v=14`, чтобы браузер не использовал старый кэш.
