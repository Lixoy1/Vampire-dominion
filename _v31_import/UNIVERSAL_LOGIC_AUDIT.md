# Universal Logic Audit v1.0

## Что было исправлено
В v0.3–v0.5 несколько значений заполненного контрольного примера не входили в список manualCells:
- BD2 — кровь за один сбор;
- BE5:BE14 — количество карт/жетонов/флаконов/бутылей;
- T/V/X/Z/AB22:25 — единицы K/M для распределения книг.

Из-за этого пустой новый пользователь мог получить расчёт с частью чужих ресурсов.

В v1.0 эти 31 ячейка перенесены в пользовательские входы. Общее число связанных входов: 314.

## Формула общего прироста
T72 состоит из:
1. U12 — Конклав;
2. Z37 — книги;
3. T46 — Дегустация;
4. U57 — прочее;
5. AW18/AW36/AW54/AW73/AW92/AW112/AW132/AW152 — блоки смотрителей;
6. SUM(AF30:AF68) — остальные смотрители.
